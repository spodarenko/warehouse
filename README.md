# Warehouse — склад сировини Delicia

Статичні сторінки (GitHub Pages, без збірки):

- `index.html` — презентація задуму: принципи, схема, три фази.
- `liquids-map/` — мапа стелажа «Рідини» + довідник: тара, правила округлення (Лінія 6, «Трубочки»), норми, дані, модель, чого бракує.
- `sklad-2/` — мапа складу №2.
- `storybook/` — UI додатку комірника: карта екранів, компоненти зі станами, теми, кольорові токени.

Переміщення на мапах зберігаються лише в браузері. Код розрахунку вимог і вивантаження 1С — поза репо.
